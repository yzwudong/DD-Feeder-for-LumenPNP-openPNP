# DD 飞达控制器 — 硬件接口说明

> 64 路 RS-485 SMT 飞达控制器

> 面向硬件、集成与维护人员。现场操作请看 [用户手册](user-manual.zh.md)。
>
> 主控：ESP32-WROOM-32E，4MB Flash，双 app 分区 + LittleFS。
> 飞达：STC8H1K 系列，RS-485 总线，P3.3 舵机 PWM。

## 1. 外部接口

| 接口 | 连接 | 用途 |
|---|---|---|
| 电源 | 5V / GND | 主控与 485 总线供电 |
| USB | 板载 USB 串口 | 调试、刷机、串口日志 |
| 上位机串口 | 贴片机上位机 | M-code 透传 |
| 飞达总线 | A / B / GND | RS-485，最多 64 台飞达 |
| 显示屏接口 | 淘晶驰 USART HMI（可选） | 本地操作屏 |
| 恢复出厂按键 | 主控板内部 | 长按 5 秒恢复出厂 |

## 2. 主控 GPIO

| GPIO | 功能 | 说明 |
|---|---|---|
| GPIO26 / GPIO27 | UART1 | 外部主机透传 |
| GPIO17 / GPIO16 | UART2 | 485 总线 TX/RX |
| GPIO4 | 485 DE | 收发方向控制 |
| GPIO18 / GPIO19 | 软串口 | 串口屏（可选） |
| GPIO21 | 485 总线电源开关 | SGM2593AD EN |
| GPIO13 | 电源故障检测 | SGM2593AD nFAULT，低有效 |
| GPIO25 | 蜂鸣器 | 无源，PWM |
| GPIO14 / GPIO32 | 校准限位 0° / 90° | 常开，到位接地 |
| GPIO34 | 恢复出厂按键 | 外部 10k 上拉，长按 5 秒 |

> GPIO 编号仅用于接线和维修；用户手册不列出引脚号。

## 3. 飞达板接口

- 485：A / B / GND，总线末端按需加 120Ω 终端电阻。
- 电源：5V / GND；N20 与舵机电源按飞达板设计。
- 舵机：P3.3，PWM 周期 20ms，脉宽约 445~2430µs。
- 限位/反馈：按飞达板版本接线。
- 烧写：UART ISP，进入方式见 [刷机说明书](flashing-guide.zh.md)。

## 4. 校准限位

| 信号 | 主控引脚 | 说明 |
|---|---|---|
| 0° 限位 | GPIO14 | 常开，到位接地 |
| 90° 限位 | GPIO32 | 常开，到位接地 |

校准为测试功能，必须在停机、飞达空闲时进行。

## 5. 存储、分区与升级

| 区域 | 偏移 | 大小 | 内容 |
|---|---|---|---|
| bootloader | 0x1000 | — | 二级引导 |
| partition | 0x8000 | — | 分区表 |
| NVS | 0x9000 | 0x5000 | WiFi、密码、事件日志、推料计数 `feedcnt` |
| otadata | 0xE000 | 0x2000 | OTA 启动选择 |
| app0 | 0x10000 | 0x1C0000 | 主控固件 |
| app1 | 0x1D0000 | 0x1C0000 | OTA 备用 |
| LittleFS | 0x390000 | 0x70000 | Web 页面资源 |

### 完整镜像会清 NVS

`DDFC_<ver>_FULL.bin` 是 4MB 完整镜像，从 `0x0` 烧录。镜像在 `0x9000` 处是 `0xFF` 填充，因此：

```text
写 FULL @0x0  ->  0x9000 NVS 被写成 FF  ->  WiFi/密码/计数/日志清空
```

- FULL 只用于**新板首次烧录**或**变砖恢复**；
- 日常升级用 Web 在线 OTA，或只烧 APP / 页面包；
- 需要保留 NVS 时，不要烧 `0x0` 完整镜像；
- `upload_full` 当前就是写 `0x0` 完整镜像，因此会清 NVS。

### 页面升级

Web 页面资源在 LittleFS。页面 OTA 只替换 `0x390000` 分区，不动 NVS，所以推料计数保留。

### 恢复出厂

`M907` / Web 恢复出厂 / 内部按键长按会执行 `nvs_flash_erase`，清空 NVS，包括推料计数。

## 6. 485 总线

- 半双工 RS-485，主控 DE 控制方向。
- 总线建议手拉手，不要星型分支。
- 末端 120Ω 终端电阻按现场情况配置。
- 总线电源可由主控 GPIO21 控制，故障时自动断电保护。

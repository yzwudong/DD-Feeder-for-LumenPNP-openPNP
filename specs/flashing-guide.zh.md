# DD 飞达控制器 — 刷机说明书

> 64 路 RS-485 SMT 飞达控制器

本说明适用于 **DD 飞达控制器** 固件与页面的升级 / 恢复刷写。

面向一线操作 / 维护人员，不需要任何开发知识。



***

## 1. 什么时候需要刷机



| 场景                 | 刷什么                                   |
| ------------------ | ------------------------------------- |
| 新板首次使用 / 设备变砖无法启动  | 完整镜像（`DDFC_<ver>_FULL.bin`）                     |
| 升级主控主程序（固件）   | **OTA 固件（`DDFC_<ver>_OTA.bin`），推荐**；完整镜像（`DDFC_<ver>_FULL.bin`）仅新板/变砖用 |
| 只更新 Web 操作页面（不改固件） | 页面包（`DDFC_<fsver>_FS.bin`）                      |
| 设备能上网，只想在线升级       | 用 Web 页面「升级」功能，**不需要刷机**              |

> ⚠️ **`DDFC_<ver>_FULL.bin` 会清空全部设置（WiFi、管理密码、推料计数、事件日志，存于 NVS 分区）**：刷完需要重新配置 WiFi。
> **日常升级主程序请用 `DDFC_<ver>_OTA.bin`（只写程序区，保留所有配置）**。
>
> 完整镜像从 `0x0` 写入，`0x9000` 的 NVS 会被写成 `0xFF`，所以 WiFi、管理密码、推料计数、事件日志都会清空；这不是页面升级造成的。
>
> 工程里的 `upload_full` 任务也是写 `0x0` 完整镜像，同样会清 NVS。
> 能进 Web 页面时优先用在线升级；只有上不了网或升级失败变砖才用本说明刷机。



***

## 2. 需要的工具和文件



* **电脑**（Windows），一根 **USB 数据线**（连接控制器板上的 USB 口）

* **ESP Flash Download Tool**（乐鑫官方烧录工具，Windows 版，百度搜 "乐鑫 Flash Download Tools" 到官网下载，选择 **ESP32** 版本）

* **固件文件**（从发布目录 `bin/` 获取）：



| 文件名                           | 作用               |
| ----------------------------- | ---------------- |
| `DDFC_26110205_FULL.bin` | 完整镜像（固件 + 页面；⚠️ 清空设置和推料计数，仅首装/变砖用） |
| `DDFC_26110205_OTA.bin`  | 仅主程序（OTA 固件；日常升级推荐，保留配置）     |
| `DDFC_20261102735b7d3a_FS.bin`    | 仅 Web 页面         |

> 文件名里的数字是版本号，以拿到的最新文件为准。



***

## 3. 升级主程序（推荐：OTA 固件，保留配置）



1. **接线**：USB 线连接控制器板与电脑。板载 USB 转串口（CH340/CP210），插上后电脑会识别一个 COM 口。

2. **打开工具**：解压并运行 `FlashDownloadTool.exe`，弹出芯片选择时选 **ESP32**。

3. **配置烧录项**：

* 点文件列表第一行右侧的 `…`，选择 `DDFC_26110205_OTA.bin`；

* 对应地址框填入 **0x10000**；

* 在 `SPI SPEED` 选 **80MHz**，`SPI MODE` 选 **DIO**。

1. **选串口**：右上角选择电脑识别到的 COM 口（如 COM3/COM8，可在 "设备管理器→端口" 里确认）。

2. **开始烧录**：点 **START**，等待进度条走完，左下角出现绿色完成提示。

3. **重启**：断电再上电（或按复位键），设备启动。

> 如果点 START 后一直等待不开始：
>
> **按住板上的 BOOT 键不放**
>
> ，再点 START，看到进度条开始后松手。

> **只刷 `DDFC_<ver>_OTA.bin` 不清除任何设置**（WiFi 密码、账号等全部保留），日常升级都用它。

### 首次使用 / 变砖：完整镜像

* 文件 `DDFC_26110205_FULL.bin`，地址 **0x0**，其余步骤同上。
* ⚠️ 完整镜像会**清空全部设置**（包括推料计数），刷完后需用热点（`SMT-Feeder-AP`）重新配置 WiFi。

## 4. 其他两种刷法

### 只刷主程序（不动页面）



| 文件                  | 地址      |
| ------------------- | ------- |
| `DDFC_<ver>_OTA.bin` | 0x10000 |

### 只刷页面（不动主程序）



| 文件          | 地址       |
| ----------- | -------- |
| `DDFC_<fsver>_FS.bin` | 0x390000 |

操作步骤与第 3 节相同，只是文件和地址换成上表。刷页面不影响设置。



***

## 5. 刷机完成后怎么确认成功



* 设备重启后，WiFi 指示灯 / 电源正常；用手机或电脑连接设备热点（或连上路由器后访问其 IP）

* 打开 Web 页面，总览页右上角「固件」显示的版本号与刷入文件的版本号一致（如 `26110205`），即刷机成功

* 页面显示正常、能扫到飞达，说明页面也正常



***

## 6. 注意事项



1. **烧录时不要接其他占用串口的软件**：关闭串口助手、调试工具等，否则报 "无法打开串口"。

2. **烧录过程中不要断电、拔线**：中途断电可能变砖，需重新完整刷一次。

3. **只刷**`DDFC_<ver>_OTA.bin`**不会影响页面和设置**：页面还是旧的，需要更新页面时单独刷 `DDFC_<fsver>_FS.bin`。

4. **完整镜像**`DDFC_<ver>_FULL.bin`**包含一切，但会清空全部设置**：首次使用/变砖才用；刷完需重新配置 WiFi（用热点 `SMT-Feeder-AP` 进 WiFi 页）。日常升级请用 `DDFC_<ver>_OTA.bin`。

5. **刷机后第一次启动稍慢**：等待 10\~20 秒再访问页面。

6. 若设备已连接路由器且能访问 Web，升级请优先用 Web 页面「升级」功能，省去接线。

## 7. 常见问题



| 现象           | 处理                                   |
| ------------ | ------------------------------------ |
| 电脑识别不到 COM 口 | 换一根数据线（有些线只充电不传数据）；安装 CH340/CP210 驱动 |
| 点 START 无反应  | 按住 BOOT 键再点 START；检查波特率是否 921600     |
| 烧录中途报错 / 失败  | 重新完整烧一次 `DDFC_<ver>_FULL.bin @0x0`，烧录时保持稳定供电    |
| 烧完不开机        | 先断电重上电；仍不行则重刷完整镜像 `DDFC_<ver>_FULL.bin`        |
| 页面能开但飞达扫不到   | 检查 485 接线与总线电源，与刷机无关                 |
